Rule
  • Swell < 1.2 m if arriving from S / SW / SE, or < 2.0 m if from N / NE / NW.
  • Wind predominantly NW→N→NE for the last 5 days.
  • Less than 30 mm of rain in the trailing 7 days.
  • All three must pass for a day to be called "Dive".
Assumptions (things I decided, not things you specified)
  • Due-west swell (247.5°–292.5°) isn't covered by your rule — treated conservatively using the tighter 1.2 m threshold.
  • "Predominantly NW→N→NE for 5 days" is implemented as: at least 4 of the last 5 days had a dominant wind direction inside the 292.5°–67.5° arc. This 4-of-5 threshold is my assumption — change it in the code if you meant something stricter or looser.
  • For a given evaluation day, the "last 5 days" window ends on and includes that day itself (using forecast wind direction for future days).
  • The 7-day rain window ends on and includes the day before the evaluation day (i.e. it doesn't count rain forecast to fall later on the evaluation day itself).
  • Swell figures use Open-Meteo's swell_wave_height_max / swell_wave_direction_dominant (the swell component only, not wind-chop or combined wave height).
  • Wind direction uses Open-Meteo's winddirection_10m_dominant daily aggregate.
